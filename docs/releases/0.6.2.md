# **codr** 0.6.2 — Linux preview

This is an opt-in development prerelease from `dev/linux`, for Linux x86-64
and ARM64 only. The stable, cross-platform release remains `v0.6.0`.

## Changes since 0.6.1

- `/sync` sends each eligible conversation's latest completed assistant reply
  to its own White Noise chat. It uses one shared cutoff: one hour before the
  last confirmed new message sent across all linked chats, not one hour before
  the command. The reference survives restarts and can be recovered from retained
  MDK history. With no confirmed send history, it falls back to the past hour.
- `/help` lists shortcuts in the requesting White Noise chat. Both commands
  are owner-only, work while muted, leave mute settings unchanged, and never
  prompt agents. Replies are durable and protected against command replay.
- Muting no longer blocks invitations or automatic chat-name and description
  updates. Introductions use bracketed lowercase labels such as `[oc]`.
- The dedicated connector is built from pinned MDK 0.14.0 source, with the
  existing founding-admin and media-recovery extensions.

## Upgrade warning: one-way MDK storage migration

MDK 0.14 rekeys account databases and changes storage on first open. **Downgrade
to MDK 0.13 is unsupported. Do not roll back only the executable or restore stale
MLS state into a running account.**

Before upgrading an existing installation:

1. Stop the bridge and dedicated connector services.
2. Make a private, device-local backup of the complete connector home and its
   secret-store credentials. Keep credentials out of chat, logs, and repositories.
3. Install this version and run Setup only when you accept the migration.

```sh
herdr plugin install tidley/codr --ref v0.6.2
herdr plugin action invoke local.white-noise.setup
```

Setup preserves the configured owner, existing account, group mappings, and
consumed-message history. It selects the release-matched connector without
creating a replacement identity. Use the version tag, not the moving branch.
macOS users should stay on `v0.6.0`.

## Build provenance

The Linux preview workflow runs Rust tests, formatting, Clippy, and Python tests,
then builds static musl bridge binaries and dedicated connectors on native
x86-64 and ARM64 runners. The connector source pin is MDK 0.14.0 commit
`3fb4b4759ac676b0c21c4c3527074866c9fa4c89`; the published patch is
`patches/mdk-codr.patch`. Connector archives include `CODR-CONNECTOR.json` and
the upstream license. Each archive has a SHA-256 sidecar.

No macOS assets are included, and this release is not marked latest. Stable
`master` and the existing published release assets remain unchanged.
